    03

    审计裁决 · Agent 不能自己改答案

    门会误报，但纠错也必须留下证据与责任边界。

    1. 越界修改被撤回

      自修轮 2 为过门缩短了已批文案，审计判违规并还原 3 条；文本变更会自动触发重克隆。

      自修白名单仅限：重跑脚本、清缓存、改几何数值。
    2. 用实测证伪误报

      4 个“疑截断”窗口经克隆源尾部 RMS 实测为 0，确认为背景音乐造成的假阳性。

      确认误报后由审计方修正检测逻辑，执行体不能自行放行。
    3. 验证规则有维护者

      同音词误杀经拼音重合 100% 证伪，审计方将规则升级为基线 v2；另一处归一化改动经审查后仅作例外追认。

      验证规则对执行 Agent 禁止修改，由审计方维护版本与阈值。
    04

    任务卡 · 把开放任务压成可判定动作

    一卡一脚本，进度写进文件，不依赖模型记忆。

    任务卡结构 · 脱敏结构重绘

卡① · 首渲
命令：运行既有渲染脚本
成功判据：exit 0，且产出新版本
报告格式：卡号 + 退出码 + 产物状态 → 下一卡

卡② · 切点门
命令：运行既有切点验证脚本
成功判据：exit 0 且输出含 PASS

任一卡 FAIL
报告格式：卡号 + 退出码 + 日志末段
动作：停车，等待审计；不得自行绕道

    每张卡固定三要素：命令、成功判据、报告格式。模型不负责重新解释“什么算完成”，只负责执行并回填机器可比对的结果。

    • 任务尺寸有限
      单卡不超过弱模型的输出预算。
    • 失败出口明确
      退出码非 0 就停车，不能带病领取下一卡。
    • 进度外置
      完成标记落在任务文件，不靠长对话记忆。

    这组原件能证明免费档模型在 P3–P5 段按卡执行，并在音频门失败时正确停车；不据此推断完整交付链路。最终质量仍需人工耳审与审计裁决。
