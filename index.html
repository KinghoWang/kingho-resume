01 企微获客链路改造 · 移除长按识别门槛

产品改造 · 已上线 · 回收数据验证
  • 问题：小程序环境无法直接唤起企微获客助手；原链路需在 H5 长按识别二维码并选择系统菜单，中老年主力用户不熟悉该操作、易在此流失
  • 方案：以小程序可唤起的企微客服会话为桥，自动下发含同一获客链接的文案与卡片，将陌生的「长按识别」替换为点击
  • 结果：北极星曝光-加微率 +50%+，辅助漏斗曝光-地址率 +40%+；质量护栏为广告主后转无损，平台效率 CPM 提升（相对提升，绝对值脱敏）

02 数分机器人 × Eval · 广告归因分析闭环

生产产品 + 内嵌质量门禁 · 团队 3 人日常使用 · 迭代 3 个月
  • 问题与方案：人工归因日报需 30-60 分钟且依赖个人经验；规则引擎检出异常并分解结构 / 效率效应，LLM 按「现象 → 根因 → 建议」叙述
  • 防幻觉：所有数值由代码计算；22 例黄金集 + 代码指标 + LLM-as-judge，3 模型 × 2 配置作 prompt 回归门禁，评测成本逐轮可对账
  • 成果：1 周产出并投入日常使用，日报从 30-60 分钟压缩为分钟级复核

Agent 无关执行契约 · 37 个 Python 脚本 / 约 3.7k 行 · 4 个 job 产出可播放主成片
