# KW 折板 Logo 设计规格

**日期：** 2026-08-19

**状态：** 待用户书面确认

**选择依据：** 用户在第二轮视觉对比稿中选择 C「KW 折板 / Folded KW」

## 1. 目标

将简历站当前基于字体字形的红底「王」favicon，替换为用户选定的「KW 折板」几何标志。新标志表达：

- `K` 与 `W` 对应 `Kingho Wang`，形成直接的个人身份关联；
- 一体式折线像钣金折板或加强筋，体现工业设计的结构感；
- 分叉、选择与继续推进的路径，呼应商业策略中的判断与落地；
- 单一红色铰点只作为 AI 协作的轻提示，不使用机器人、闪光、神经网络等通用 AI 图形。

本次 Logo 的主要使用场景是浏览器标签页及收藏夹。成功标准不是放大后复杂，而是原生 `16px` 仍有稳定、可辨认的轮廓。

## 2. 视觉定稿

### 2.1 构图

- 底板：深墨绿色圆角正方形。
- 主标：一体式白色折线构成 `K` 与 `W`。
- 铰点：折线衔接处放一个红色方形节点。
- 内部线段只使用竖线和斜线；端点方切、转角硬朗，不使用圆头、阴影、渐变、描边叠层或文字字形。

### 2.2 颜色

| 角色 | 色值 | 用途 |
|---|---|---|
| 深墨绿 | `#18211e` | 实色底板 |
| 白色 | `#ffffff` | 主体 KW 折板 |
| 克制红 | `#c0392b` | 唯一铰点 |

白色主体承担识别，因此保持高对比。红色节点是装饰性含义，不承担可访问性信息，也不作为独立状态提示。

### 2.3 16px 光学母版

正式 SVG 使用 `viewBox="0 0 16 16"`，直接以原生像素坐标绘制：

- 底板：`x=0, y=0, width=16, height=16, rx=2`
- 连续折线：`M4 3V13 M4 8L8 4 M4 8L8 12L10 5L12 12L14 4`
- 主线：白色、`stroke-width=2`、`stroke-linecap=square`、`stroke-linejoin=miter`
- 红色铰点：`x=7, y=7, width=2, height=2`

所有关键线段至少 `2px`，含方切端点在内不得触碰或越出画布；右上端点保留接近 `1px` 的视觉留白。禁止再向 16px 版本添加折痕、暗线、字母缺口或第二个强调色。

### 2.4 64px / 256px 光学校正母版

用户选中的 C 稿在大尺寸中使用独立光学校正，正式资产保留这一差异：

- 底板：`x=0, y=0, width=64, height=64, rx=8`
- 一体式折线：`M15 12V52 M15 32L31 14 M15 32L31 50L39 22L47 50L55 14`
- 主线：白色、`stroke-width=7`、`stroke-linecap=square`、`stroke-linejoin=miter`
- 红色铰点：`x=28, y=29, width=7, height=7`

`favicon.svg` 使用 16px 母版，优先保证浏览器标签页与收藏夹的小尺寸识别；`favicon.png` 使用 64px 光学校正母版等比生成 `256×256` PNG。两套母版只允许上述坐标和线宽差异，不增加新构件或新颜色。

## 3. 文件范围

### 3.1 修改

- `favicon.svg`：改为纯 `path` / `rect` 的 KW 折板标志，不再使用 SVG `<text>` 或字体 fallback。
- `favicon.png`：由 64px 光学校正母版生成的 `256×256` PNG。
- `tests/resume-content.spec.js`：增加 favicon 资产合同与页面引用回归测试。
- 本地权威源中的 `favicon.svg`（路径运行时解析，不进入公开仓库）。
- 本地权威源中的 `favicon.png`（路径运行时解析，不进入公开仓库）。

### 3.2 不修改

- `index.html`、`en.html`、`cases.html` 的正文与布局；现有 favicon 文件名和引用保持不变。
- `og-image.png`；本轮仅更换浏览器 Logo，不扩展为社交分享图改版。
- 头像、微信二维码、PDF、Word、项目文案、工作经历、教育经历及所有 Demo。
- 不新增 `favicon.ico`、页头字标、动画或 Logo 说明文案。

## 4. 验收

### 4.1 自动检查

- `favicon.svg` 可解析，`viewBox` 为 `0 0 16 16`，且不含 `<text>`、外部资源、脚本或字体引用。
- SVG 仅包含定稿色值，PNG 尺寸严格为 `256×256`。
- `index.html`、`en.html`、`cases.html` 继续同时引用 `favicon.svg` 与 `favicon.png`。
- 全仓既有 Playwright、链接检查和公开素材隐私检查全部通过。
- Git Diff 不包含 `.superpowers/` 视觉草稿、Logo 之外的页面内容或其他资产变化。

### 4.2 视觉检查

- 以 SVG 母版渲染原生 `16px`、`32px`，以 PNG 母版渲染 `64px`、`256px`，确认图形非空、无裁切、无异常毛刺。
- 在浅色与深色浏览器标签栏中目测：深色底板边界可辨，白色 KW 主体清楚，红色铰点不吞掉折线结构。
- 检查中文首页、英文页和作品集页的实际标签页 favicon 均已更新；页面本身的排版、头像和内容不得发生变化。

## 5. 发布边界

用户确认本规格后再实施。完成后只提交规格列出的资产与测试，推送前再次检查 author / committer 使用 GitHub noreply；Pages 成功后，以带 cache-bust 参数的线上 URL 回读 SVG / PNG，并与本地权威源（路径运行时解析，不进入公开仓库）、仓库文件逐字节比对。
