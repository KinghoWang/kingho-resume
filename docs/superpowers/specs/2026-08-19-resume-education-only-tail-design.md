# 简历站第 3、4 区收敛设计

日期：2026-08-19

## 目标

将简历站尾部从「技能与证书 + 教育经历」收敛为单一教育区，删除缺少增量价值或可能引发错误能力预期的技能、工具、平台和证书清单。保留页面前两区现状，并补入一条已经用户确认准确的大学经历。

## 已确认方案

采用对比稿中的 C 方案：

1. 完整删除中文页现有「3 技能 & 证书」及英文页现有「3 Skills & Certifications」。
2. 原教育经历由第 4 区升为第 3 区。
3. 页面不再设置第 4 区，也不以其他内容填补空位。
4. 教育卡保留学校、专业、学位和时间，并新增已核实的学生工作与荣誉。

## 最终文案

中文：

> 北京师范大学（珠海） · 工业设计 · 工科学士
>
> 校团委宣传部学生干部，获校级优秀学生干部（前 10%）。

英文：

> Beijing Normal University (Zhuhai) · Industrial Design · B.Eng.
>
> Student leader in the University Youth League Committee's Publicity Department; recognized as an Outstanding Student Leader (top 10%).

## 排版

- 继续复用现有教育时间线卡片，不引入新的组件体系。
- 新增荣誉行作为卡片内的次级说明，字号与工作经历正文一致，保证可读但不抢学校与学位层级。
- 删除技能区后自然缩短页面；不人为增加留白、统计墙或装饰卡片。
- 桌面和手机均保持单列教育卡，无横向溢出、截断或文字重叠。

## 修改范围

本轮仅修改：

- `index.html`
- `en.html`
- 与该变化直接相关的最小 CSS（仅在现有样式无法满足时）
- 与该变化直接相关的页面回归测试

本轮明确不修改：

- 首页与第 1 区项目经历
- 第 2 区工作经历
- PDF、Word 与生成脚本
- `cases.html` 和任何 `demo-*.html`
- GitHub 个人主页 README

## 验收标准

1. 中英文页均不再出现技能、工具、投放平台或证书清单。
2. 中英文页教育标题编号均为 `3`，且页面不存在编号 `4` 的内容区。
3. 中文和英文大学经历逐字符合本规格。
4. 项目经历与工作经历的文字和结构保持不变。
5. 页面本地链接检查、HTML 结构检查和现有 Playwright 全量测试通过。
6. `360 / 390 / 768 / 1024 / 1440` 视口下无横向溢出、截断或重叠，页脚正常显示。

## 明确边界

调研得到的 Prompt、Agent 质量控制和 Eval 量化证据本轮不进入页面。它们留作后续候选内容，只有在形成比当前项目描述更明显的增量价值、且用户再次确认后才新增。
