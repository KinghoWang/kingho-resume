# 简历首页联系方式与工作经历收敛设计

**日期：** 2026-08-20
**状态：** 用户已确认设计，待实现

## 目标

在不改变网站整体视觉体系的前提下，解决首页四个问题：

1. 邮箱和电话点击后改为直接复制，并明确提示复制成功。
2. 微信仍通过弹层展示二维码和微信号，但入口本身要能让用户看出可以展开。
3. 首页作品集入口从旧的 Demo 数量口径改为当前三个项目案例。
4. 降低“操盘者”等夸大表达，并把太字流动工作经历收敛为更符合广告运营执行岗事实的两条职责与成果。

## 已确认方案

### 联系方式

采用用户选择的 A“明确但克制”方案：

- 邮箱与电话由 `mailto:` / `tel:` 链接改为复制按钮，视觉继续沿用当前内联文字与下划线，不改成厚重胶囊或卡片。
- 两个按钮各保留完整联系方式，并在文字末尾显示小型复制图标；图标只用于表达动作，不替代可读文本。
- 点击邮箱后复制 `kinghowang@foxmail.com`，点击电话后复制 `17512006748`，不附加 `mailto:`、`tel:`、空格或国家代码。
- 复制成功后显示独立状态提示“邮箱已复制”或“电话已复制”；英文页对应为“Email copied”或“Phone copied”。提示自动消失，不改变联系方式行的尺寸和位置。
- 状态提示使用 `role="status"` 与 `aria-live="polite"`，键盘用户也能获得反馈。
- 优先使用 `navigator.clipboard.writeText`，失败或不可用时复用页面现有的临时 `textarea` + `document.execCommand('copy')` 回退方式；两种方式都只有成功后才显示成功提示。
- 微信入口文案改为“微信 / 二维码”并带向下箭头；英文页为“WeChat / QR code”。入口继续打开原有 `dialog`，二维码、微信号、弹层内复制按钮、关闭方式和点击遮罩关闭行为均不变。

### 作品集数量

- 中文首页入口改为“作品集：3 个项目案例 →”。
- 英文首页入口改为“Portfolio: 3 project cases →”。
- 三个案例指 `cases.html` 当前保留的企微获客链路、AI 创意生产与投放验证、AI 广告日报与问题排查。
- 五个公开 Demo 仍分别嵌在三个案例中。本轮只纠正首页入口的阅读单位，不删除 Demo，也不把 README 的 Demo 总表误改为三个。

### 首屏定位降调

中文首页统一删除“操盘者 / 操盘”措辞：

- 标签行“5 年商业化操盘”改为“5 年广告运营经验”。
- 自我介绍开头“5 年商业化广告操盘者”改为“5 年商业化广告运营经验”。
- 自我介绍中的职责衔接改为“工作重点从投放执行逐步延伸到策略、数据和产品改造”，明确正式岗位仍是执行岗。
- “主导中医 & 大健康行业”改为“负责中医 & 大健康行业”。
- 页面 `description` 与 Open Graph 描述同步删除“操盘”口径。

英文页同步表达为 “five years in commercial ad operations”，不得使用 operator、owner 或其他暗示经营负责人身份的词。

## 太字流动工作经历

采用用户选择的 A 方案，将当前三条收为以下两条：

1. **行业商业化运营：** 负责中医 & 大健康行业从冷启动到规模化，预算占比 **5% → 90%+**；参与行业商业化策略制定与落地。
2. **客户组合与预算保障：** 服务 **60+ 客户**，覆盖兴趣教育与中医大健康，年消耗 **3 亿+量级**；负责行业趋势分析、消耗监控和预算稳定性保障。

删除当前“数据驱动决策”和“素材与链路策略”两条，不把工具、财务对账、CTCVR 或自建站 A/B 换一种说法重新塞回工作经历。上述事实均来自既有简历源与历史履历，不新增未经确认的客户协同、收入归因、节省比例或组织职责。

英文页同步为两条等义描述，保持数字、职责边界和语气强度一致。

## 交互与视觉

- 联系方式继续保持当前横向换行布局、圆点分隔与页面字体，不引入新图标库。
- 复制图标使用 CSS 绘制的双矩形符号，颜色继承文字；鼠标悬停和键盘聚焦继续使用现有红色强调。
- 微信箭头与文案作为同一个按钮点击目标，最小点击高度在移动端达到 44px；邮箱和电话按钮在移动端同样满足该点击高度。
- 复制状态提示使用固定定位，位于视口底部安全区域上方，避免挤动首屏或覆盖微信弹层的主要操作。
- `prefers-reduced-motion` 下只保留状态显隐，不执行位移动画。
- 360、390、1024、1440 宽度下，联系方式不得横向溢出、相互遮挡或与求职意向标签重叠。

## 可访问性与错误处理

- 邮箱和电话必须使用原生 `button type="button"`，并提供明确的 `aria-label`，例如“复制邮箱 kinghowang@foxmail.com”。
- 复制图标设置为装饰性，不重复朗读。
- 成功提示由同一个状态容器输出；连续复制时应更新文本并重新开始自动隐藏计时。
- 两种复制方式都失败时显示“复制失败，请手动复制”或英文等义文案，不得误报成功。
- 微信按钮保留 `aria-haspopup="dialog"`，并增加 `aria-controls="wechatDialog"`；弹层原有焦点和关闭逻辑不退化。

## 修改范围

- `index.html`：中文联系方式、三案例入口、首屏与太字流动文案、复制交互脚本。
- `en.html`：英文等义同步。
- `style.css`：复制按钮、复制图标、微信展开箭头、状态提示与移动端点击区域。
- `tests/resume-content.spec.js`：联系方式复制、状态提示、微信入口、三案例口径、降调文案和两条工作经历回归。
- 仅在确有现成断言受影响时，外科手术式调整其他相关测试。

## 验收标准

1. 点击中文和英文邮箱按钮，剪贴板分别得到精确邮箱文本，并出现本地化成功提示。
2. 点击中文和英文电话按钮，剪贴板得到 `17512006748`，并出现本地化成功提示。
3. 复制成功提示不引发布局位移；连续点击邮箱和电话时文本与隐藏计时正确更新。
4. 微信入口分别显示“微信 / 二维码”和“WeChat / QR code”，点击后仍打开原有弹层；二维码、微信号复制和关闭行为正常。
5. 中英文首页分别显示“3 个项目案例”和“3 project cases”，不再显示“5 个在线 Demo / 5 live demos”。
6. 中文页面和元信息不再出现“操盘者”“商业化操盘”“行业变现操盘”；英文不使用暗示经营负责人的等义词。
7. 太字流动只保留两条已确认工作经历，数字与职责边界逐字符合本设计。
8. Playwright 定向回归通过；360、390、1024、1440 四档无横向溢出、重叠或文本裁切，浏览器控制台无错误。
