## 🛠 技术

纯静态 `HTML / CSS / JS`，无需构建，GitHub Pages 托管。Demo 的演示逻辑保留在各自页面，公共导航由 `demo-nav.css` / `demo-nav.js` 提供，发布时须一并上传。系统字体栈，无需在线字体服务。

Demo 根据入口参数返回对应简历项目或作品集案例，英文简历入口保留英文返回地址；直接打开 Demo 默认返回简历。顶部始终保留简历主页与作品集入口，不依赖浏览器历史或来源页记录。
