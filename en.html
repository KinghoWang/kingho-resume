01 Analytics Agent × Eval · Attribution Analysis Loop

Production product + embedded quality gate · Daily use by a team of 3 · Iterated 3 months · Human-in-the-loop
  • Problem: writing daily anomaly-attribution reports took 30-60 min/day, depended on personal experience, hard to scale or hand over
  • Solution: scripts pull 8 days of market / industry / client data from the warehouse → rule engine does threshold anomaly detection and structure/level effect decomposition → a prompt with "observation → root cause → action" structure and attribution red lines → LLM writes the narrative
  • Reliability and Eval: all numbers are computed by code; the model only narrates. An embedded gate uses 22 annotated reports, code metrics and LLM-as-judge to measure numeric fidelity, anomaly recall / precision, attribution quality and fabricated-mechanism rate
  • Evidence: built in 1 week, used daily by a team of 3, and reduced reporting to minutes of review; 3 models × 2 configurations produce comparable, auditable results

02 “Wukong” Agent × AI Video Repurposing Pipeline

Agent-agnostic execution contract · Video pipeline: 37 Python scripts / ~3.7K lines (including validation and tests) · 4 jobs produced playable master videos
  • Reliable delivery: 8 core automated QA gates, a self-repair loop and a JSON contract for human review. Only verification-script output counts; an agent’s self-report of “done” does not.
  • Execution guardrails: the contract forbids Agent edits to gate scripts; self-repair is limited to rerunning scripts, clearing caches or changing geometric values, while non-verifiable judgments go to human review
  • Cost engineering: one-card / one-script tasks and file-based progress support recovery after disconnects, allowing free-tier models to complete the main workflow from decomposition through rendered-video QA
