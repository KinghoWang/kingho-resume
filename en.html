01 WeCom Acquisition Flow · Removing the Long-Press Barrier

Product redesign · Deployed · Validated with post-launch data
  • Problem: the mini-program could not invoke WeCom's acquisition assistant directly. The fallback H5 flow required long-press QR recognition and a system-menu choice; many older users were unfamiliar with the gesture and dropped off
  • Solution: use a supported WeCom customer-service chat as the bridge, automatically sending text and a card with the same acquisition link so either familiar tap opens the contact flow
  • Result: north-star impression-to-WeCom-contact conversion +50%+; supporting impression-to-address conversion +40%+; downstream advertiser conversion held flat as the quality guardrail, while efficiency CPM improved (relative lift; absolute values sanitized)

02 Analytics Agent × Eval · Attribution Analysis Loop

Production product + embedded quality gate · Daily use by a team of 3 · Iterated 3 months
  • Problem and solution: daily anomaly-attribution reports took 30-60 minutes and depended on personal experience; a rule engine detects anomalies and decomposes structure / efficiency effects before the LLM writes "observation → root cause → action"
  • Anti-hallucination: all numbers are computed by code; 22 annotated reports, code metrics and LLM-as-judge across 3 models × 2 configurations form the prompt regression gate
  • Result: built in 1 week, used daily by a team of 3, reduced reporting to minutes of review; evaluation cost is auditable at ¥0.45 per run

03 “Wukong” Agent × AI Video Repurposing Pipeline

Agent-agnostic execution contract · 37 Python scripts / ~3.7K lines · 4 jobs produced playable master videos
  • Reliable delivery: 8 core automated QA gates, a self-repair loop and a JSON contract for human review. Only verification-script output counts; an agent’s self-report of “done” does not.
  • Execution guardrails: the contract forbids Agent edits to gate scripts; self-repair is limited to rerunning scripts, clearing caches or changing geometric values, while non-verifiable judgments go to human review
  • Cost engineering: one-card / one-script tasks and file-based progress support recovery after disconnects, allowing free-tier models to complete the main workflow from decomposition through rendered-video QA
