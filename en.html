Analytics Agent · Ad Daily Report (Rule Engine + LLM Attribution)

Self-built · Design + implementation · Daily use by a team of 3 · Iterated 3 months · Human-in-the-loop
  • Problem: writing daily anomaly-attribution reports took 30-60 min/day, depended on personal experience, hard to scale or hand over
  • Solution: scripts pull 8 days of market / industry / client data from the warehouse → rule engine does threshold anomaly detection and structure/level effect decomposition → a prompt with "observation → root cause → action" structure and attribution red lines → LLM writes the narrative
  • Anti-hallucination by architecture: all numbers are computed by code and fed in; the model does no arithmetic — it only narrates
  • Outcome: built in 1 week; daily use by 3 teammates; report time cut from 30-60 min to minutes of review; attribution quality quantified by the Eval project below

“Wukong” Self-Built Agent × AI Video Repurposing Pipeline

Agent-agnostic execution contract · Video pipeline: 37 Python scripts / ~3.7K lines (including validation and tests) · 4 jobs produced playable master videos
  • Deliverable pipeline: engineered AI-assisted video repurposing into a controlled workflow with 8 core automated QA gates (v2 baseline), covering OCR text residue, boundary-frame sampling, motion share, duration, and audio; paired with a self-repair loop and a JSON contract for human review
  • Guardrails for an unreliable executor: Only verification-script output counts; an agent’s self-report of “done” does not. The execution contract forbids Agent edits to gate scripts, while self-repair is limited to three allowlisted operations: rerun scripts, clear caches, or adjust geometric values. Three-way capability routing assigns machine-verifiable work to scripts, proxy evidence to review, and only four predefined cases to a human; each of ten hard rules traces back to an observed failure
  • Cost engineering: split long instructions into one-card / one-script task cards and persisted progress to files rather than model memory, enabling free-tier models to complete the main workflow from decomposition through rendered-video QA and resume from the last verified card after disconnects
